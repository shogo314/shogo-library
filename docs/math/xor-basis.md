追加した値をいくつか選んで XOR したときに作れる値の集合 (F2 上の線形空間) を管理する `XorBasis<T>` です。`T` は 64 ビット以下の符号なし整数型で、省略すると `unsigned long long` です。$B$ は `T` のビット数です。

```cpp
XorBasis<> xb;
xb.add(5);           // true (基底が増えた)
xb.add(3);           // true
xb.add(6);           // false (5 ^ 3 なので作れる)
xb.contains(6);      // true
xb.rank();           // 2 (作れる値は 2^2 = 4 個: 0, 3, 5, 6)
xb.max();            // 6
xb.max(1);           // 7 (1 ^ 6)
xb.kth(2);           // 5 (小さい方から 0-indexed で 2 番目)
```

## メンバ関数

| 関数 | 説明 | 計算量 |
|---|---|---|
| `XorBasis<T>()` | 空の状態 (作れる値は 0 だけ) | $O(B)$ |
| `add(x)` | `x` を追加する。`x` がまだ作れない値なら (基底が増えたら) `true` | $O(B)$ |
| `rank()` | 基底の個数。作れる値は $2^{\mathrm{rank}}$ 個 (0 を含む) | $O(1)$ |
| `contains(x)` | `x` を作れるか | $O(B)$ |
| `max(x = 0)` | 作れる値 `y` についての `x ^ y` の最大値。`x = 0` なら作れる値の最大値 | $O(B)$ |
| `min(x)` | 作れる値 `y` についての `x ^ y` の最小値 | $O(B)$ |
| `kth(k)` | 作れる値のうち小さい方から `k` 番目 (0-indexed) の値。$k < 2^{\mathrm{rank}}$ であること | $O(B)$ |
| `count_less(x)` | 作れる値のうち `x` より小さいものの個数 (`kth` の逆) | $O(B)$ |
| `basis()` | 基底を最上位ビットの降順に並べたもの | $O(B)$ |

基底は、最上位ビットがすべて異なり、各基底の最上位ビットがほかの基底では 0 になる形 (簡約された形) に保っています。このため `kth(k)` は、`k` の $i$ ビット目が立っていれば最上位ビットが小さい方から $i$ 番目の基底を XOR したものになります。

- 「空でない部分集合の XOR」を考える問題では、`add` が `false` を返した (従属な値があった) かどうかで 0 を作れるかが変わることに注意してください。
- 符号付きの値を渡すときは `XorBasis<unsigned long long>` などにして、非負の値を渡します。
